# PM-004 Toast Phone Case render set

## Product lock

- One manufacturable phone case shaped like a single slice of toast.
- Cream porous bread-crumb texture across the back.
- Evenly browned caramel crust around the perimeter.
- Raised camera lip, tactile button covers, speaker holes, and charging-port opening.
- Generic modern premium smartphone with no Apple logo or copyrighted UI.
- Small debossed `TOAST` mark only where visible.
- Warm off-white studio palette with soft grounded shadows.
