# PM-013 v02 · 제작 검수

2026-09-10 09:33 KST. Remotion 제작 가이드에 따라 고정된 한영 레이아웃, 편집 가능한 장면 분리, 재현 가능한 렌더, 로컬 미리보기 검수를 적용했다.

## 확인한 사항

- `npm run lint`: ESLint와 TypeScript 통과.
- `node scripts/render-pm013-explain.mjs`: 표지, X 이미지, 세 장면 확인용 정지 이미지, MP4 생성 완료. v01 파일은 변경하지 않음.
- 완성 MP4: 정확히 9.000초, 1080×1920, 30fps, 270프레임. H.264 High, 실제 디코더 표기 `yuvj420p`(full-range 4:2:0), AAC stereo 48kHz. 파일 2,136,329바이트. Fast-start 처리 및 AAC 패딩 길이 정리 완료.
- 세 장면(0, 100, 190프레임), 9:16 표지, 4:5 X 이미지를 직접 열어 글자·제품·콘셉트 표시를 확인. 헤드라인과 이미지 영역은 장면마다 동일 위치/크기.
- 표지 중요 요소는 중앙 정사각형 크롭 y=420–1500 안에 배치: 한글 제목 y=430부터, 영어 y=632부터, 전체 제품 이미지 y=740–1410, 콘셉트 표시 y=1428–1496. 3:4 중앙 크롭에도 들어간다. 상단 브랜드는 정사각형 크롭에서 생략될 수 있으나 제목·제품은 유지된다. 실제 앱 업로드 크롭은 공개 직전 별도 검수한다.
- 로컬 Studio에서 새 세 구성을 확인하고 영상 재생·일시 정지 가능함을 확인. 임의로 로딩 아이콘이나 가짜 작동 모션을 넣지 않았다.
- 최종 MP4의 blackdetect(d=0.05, pix_th=0.10): 검은 프레임 구간 검출 없음.
- 최종 음원 측정: -16.96 LUFS integrated, -4.02 dBTP true peak. 입력 게이트 -26.96 dB를 기준으로 0.5초 이상의 무음 구간 검출 없음. 외부 곡·외부 샘플 없이 기존 자체 합성 9초 트랙을 재사용.
- X 문안 보수적 가중 길이 174로 280 이내. 실제 업로드 입력란 제한도 게시 시 재확인.
- 추이 관찰 JSON 파싱·관찰 ID 중복 검사 통과. 미확인 지표는 0으로 채우지 않음.

## 내용 정확성 및 남은 단계

원본 04는 수화기를 들고 있는 모습이 아니므로 기존 v01의 들기/풀림 성능 설명을 그대로 쓰지 않았다. 05는 검증된 제작 도면이 아닌 콘셉트 그림이다. “수화기를 놓으면 테이프가 잘린다면?”으로 설계 의도만 설명한다. 모든 결과에 미제작 표시를 넣고 영상에는 정지 이미지 편집이라는 표시를 추가했다.

관리자 사이트에서 로그인 화면을 확인했으며 저장·공개는 하지 않았다. SNS 업로드, AI 표시, 중복 확인, 게시 후 표지/오디오 확인, 사이트 공개와 복수 링크 추가는 아직 남아 있다. 새 예약·유료 집행도 없다.
