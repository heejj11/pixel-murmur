## 1. 기록 원칙

1. Instagram과 X는 별도 표로 기록한다. 두 플랫폼의 `views` 또는 `impressions`를 같은 의미로 보거나 합산하지 않는다.
2. 유기적 성과와 유료 성과는 게시물·캠페인·비용 단위까지 완전히 분리한다. 유료 집행이 없으면 `0` 대신 `not run`을 쓴다.
3. 앱 화면 또는 API에서 실제로 확인된 원시값만 입력한다. 제공되지 않는 지표는 `N/A`, 로그인·권한 부족으로 보지 못한 값은 `미확인`, 아직 수집 전이면 `pending`으로 둔다. 셋 모두 0으로 바꾸지 않는다.
4. 비율은 분모를 함께 남긴다. 예: `저장률 = 저장 / 도달 계정`, `프로필 행동률 = 프로필 방문 / 도달 계정`. 분모가 없으면 비율을 만들지 않는다.
5. 의미 있는 댓글과 명시적 시제품 의향은 사람이 원문을 읽고 분류한다. 같은 사용자의 반복 표현은 1명으로도 별도 기록한다.
6. 좋아요보다 저장, 공유·재게시, 의미 있는 댓글, 프로필 행동, 팔로우, 명시적 시제품 의향을 우선한다.
7. 삭제되거나 수정된 게시물은 같은 표본으로 취급하지 않는다. 캡션·커버·영상·게시 시각 중 하나라도 바뀌면 새 실험 행을 만든다.

### 반응 분류

- `meaningful comment / 의미 있는 댓글`: 사용 상황, 기능, 형태, 가격 기대, 개선점처럼 판단에 도움이 되는 구체적 내용
- `explicit prototype intent / 명시적 시제품 의향`: “만들어 달라”, “실물로 보고 싶다”, “프로토타입에 참여하고 싶다”, “구매 의향이 있다”처럼 실제 객체화를 직접 원하는 표현
- 이모지, 단독 감탄, 일반 칭찬은 원시 댓글 수에는 포함하지만 위 두 분류에는 포함하지 않는다.

## 5. 진단과 단일 의사결정 규칙

각 플랫폼·각 체크포인트 리뷰에는 아래 진단 중 **관찰값이 가장 직접적으로 지지하는 하나**를 적는다.

- `insufficient distribution`: 정상 게시됐지만 콘텐츠 소비를 판단할 만큼 배포되지 않음
- `weak first frame or hook`: 충분히 노출됐으나 초반 시청·소비가 같은 플랫폼의 비교 가능 게시물보다 약함
- `unclear explanation`: 시청은 발생했지만 기능 오해, 낮은 저장·프로필 행동, 설명 질문이 반복됨
- `weak object appeal`: 설명을 이해한 반응은 있으나 저장·공유·시제품 의향이 반복해서 약함
- `insufficient sample`: 게시물 수나 실제 반응 인원이 적어 위 원인을 구분할 수 없음

리뷰의 권고는 아래 순서로 판정해 **정확히 하나만** 쓴다.

1. 비교 표본이 부족하고 치명적인 게시 결함이 없다 → `continue`
2. 한 원인을 지지하는 비교 가능한 관찰값이 있고, 아직 그 원인을 한 번도 시험하지 않았다 → `change one variable and retest`
3. 같은 작품에서 서로 다른 표현 두 개가 같은 약점을 보였거나 게시 결함으로 관찰이 불가능하다 → `hold`
4. 저장·공유·의미 있는 댓글·프로필 행동·시제품 의향 중 하나 이상이 같은 플랫폼의 최근 비교 가능 중앙값을 서로 다른 형식 또는 게시물 두 개에서 반복해서 웃돈다 → `expand`
5. 3~4주 유기적 기록과 반복 승자 두 개가 있고 유기적으로 이미 강한 소재다 → `paid-test candidate`

동시에 여러 조건이 맞으면 더 많은 지출이나 공개를 의미하는 판정보다 증거가 더 필요한 판정을 우선한다. `paid-test candidate`는 집행 승인이 아니라 제안서를 작성해도 된다는 뜻뿐이다.

### 판정별 최소 관찰 기간과 종료 조건

| 권고 | 최소 관찰 기간 | 종료 조건 |
| --- | --- | --- |
| continue | 현재 게시물 72시간, 가능하면 7일 | 다음 체크포인트 값 확보 또는 비교 가능한 동일 형식 게시물 추가 |
| change one variable and retest | 수정본 게시 후 72시간, 최종 7일 | 같은 작품의 두 번째 수정 시험 완료 시 추가 수정 중단 |
| hold | 약한 표현 두 개의 각 7일 관찰 | 최소 4주 보류 후 새 증거가 생길 때만 재검토 |
| expand | 후속 게시물 최소 72시간 | 다음 비교 가능 게시물에서 깊은 반응 우위가 반복되지 않으면 확대 중단 |
| paid-test candidate | 최소 3~4주 유기적 기록 | 정확한 KRW 상한을 포함한 운영자 승인 없이는 자동 종료(미집행) |

## 8. 유료 테스트 안전선

첫 주에는 광고를 제안하거나 집행하지 않는다. 먼저 최소 3~4주의 Instagram·X 유기적 데이터를 각각 확보하고, 같은 플랫폼에서 깊은 반응이 반복된 승자 두 개를 확인한다. 약한 유기 콘텐츠를 살리기 위한 광고는 후보로 올리지 않는다.
