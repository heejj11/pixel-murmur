2026-09-08 20:11:38 KST, 사용자의 “다음꺼 올려보자” 요청으로 [3장 디자인 선택 게시물](https://www.instagram.com/pixelmurmur/p/DdBjKhBkvkv/)을 공개했다. 기존 v04 릴스와 별도로 공개된 X v04 영상은 유지했다. [공개 기록](launch-record.md) · [상태](status.json) · [관찰값](observations.json)

## 이번 개선

- 긴 작품 소개에서 하나의 구체적인 디자인 선택으로 전환: “얼굴, 있어야 할까?”
- 세 장의 캔버스·브랜드·제목·본문·고지 위치를 통일했다. 비교 표지는 A/B를 같은 크기로 나란히, 상세 두 장은 같은 배치로 구성했다.
- A는 기존 화면·픽셀 표정을 유지하고, B는 화면 면을 크림색 패널로 바꾼 콘셉트다. 기존 웹사이트 제품 디자인을 교체하지 않는다.
- 첫 표지는 좌우 제품 끝을 안쪽으로 이동해 좁은 썸네일의 잘림 위험을 줄였다. 공개 시 기본 정사각형 크롭의 잘림을 발견해 원본 세로 비율로 바꿨고, 실제 업로드·프로필 썸네일·공개된 세 장을 모두 검수했다.
- 한영 병기, AI 생성 및 미제작 고지를 세 장 모두에 유지했다. 성능·가격·실물 제작을 주장하지 않는다.

## 가설과 판단 범위

- 구체적인 시각적 선택을 제시하면 추상적인 “어때요?”보다 이유가 포함된 반응을 얻을 수 있다는 가설이다. 성과는 아직 없다.
- 이는 무작위 노출 A/B 테스트가 아니라 한 게시물 안의 디자인 선호 질문이다. 표본·위치 효과가 있으므로 응답으로 전체 시장 선호나 수요를 단정하지 않는다.
- B의 충전 상태 표시 방식은 아직 미정이며 본문에서 밝힌다. 가상안이 더 저렴하거나 성능이 좋다는 주장은 하지 않는다.
- 공개 시에는 서로 다른 참여자의 선택·이유, 저장·공유·프로필 행동을 관찰한다. 안 보이는 값은 null로 둔다.
- 이 추가 표현까지 약하면 같은 토스트 소재를 계속 다시 만들지 않고 다른 작품 또는 실제 작업 과정으로 전환을 검토한다.

## 계정 확인에서 발견한 점

- 웹 계정 상태의 삭제 콘텐츠·연령 접근·사용 불가 기능은 초록 체크였다. 일반 비팔로워 추천 자격은 별도 항목이 없어 미확인이다.
- 최초 확인(16:46 KST) 당시 계정 유형 화면이 ‘프로페셔널 계정으로 전환’을 제공하므로 개인 계정으로 보였다. 인사이트/API 연결을 위해 크리에이터 전환 승인을 요청했다.
- 최초 확인 때에는 크리에이터/비즈니스 선택 화면까지만 열었고 설정을 변경하지 않았다. 낮은 노출의 원인이 개인 계정이라는 뜻은 아니다.

### 후속: 크리에이터 전환 완료 · 2026-09-08 17:31 KST 확인

- 사용자가 무료 전환을 승인한 뒤, 크리에이터 / 예술 카테고리로 전환했다. 프로필 카테고리 표시는 껐고 공개 연락처는 추가하지 않았다. 광고·유료 인증·결제는 진행하지 않았다.
- Instagram의 크리에이터 전환 완료 문구, 프로필의 프로페셔널 대시보드 메뉴, 실제 계정 인사이트 로딩을 확인했다.
- 이미 공개된 브랜드 계정이다. 전환 확인창은 공개 상태·검색 엔진 노출·대기 팔로워 요청 자동 승인을 안내했다. 별도 검색 엔진 공개 설정 및 대기 요청 수는 확인하지 않았다.
- 최초 최근 30일 인사이트: 조회수 363, 조회한 사람 291, 반응 5, 프로필 방문 9, 팔로워 1. 전환 직후 읽은 기존 기간 집계이며 전환으로 새로 생긴 성과가 아니다. 상세 값과 해석 주의사항은 account-check.json의 conversionFollowUp에 기록했다.
- 이번에는 계정 유형만 전환하고 인사이트를 확인했다. API 자동 수집 연결, SNS 게시, 기존 일정 변경은 하지 않았다. Obsidian에는 기록하지 않았다.

## 생성·검수·공개 상태

내장 이미지 생성 도구(imagegen 스킬)를 사용했다. CLI/API 별도 호출·유료 도구 구매는 하지 않았다. 프롬프트 전체는 prompts.json에 보존했다.

최초 준비 작업에서는 이미지와 문구를 이 디렉터리에만 추가했다. 이후 9월 8일 사용자의 공개 요청으로 세 장을 게시했다. 준비된 한영 본문과 대체 설명을 그대로 사용했고 AI 표시도 공개 화면에서 확인했다. 정지 이미지 캐러셀로 음악은 추가하지 않았다.

기존 반응 확인 일정 `v04`의 20:45 KST 실행에 이번 게시물의 초기 관찰을 포함했다. 예약 시각은 바꾸지 않았으며, 약 33분 값은 성공·실패 판단에 쓰지 않는다. 사이트의 기존 URL은 보존하고 이번 Instagram URL 및 별도 X v04 URL을 추가해야 하지만, 관리자 세션이 로그아웃되어 저장하지 않았다. Obsidian에는 기록하지 않았다.
