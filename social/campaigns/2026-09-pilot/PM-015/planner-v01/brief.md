# PM-015 · 다이어리 날짜 스탬프 첫 시험

- 승인: 2026-09-14 운영자의 “그래보자”. PM-013 반복 변주 대신 PM-015를 다이어리·문구 관심층에게 보여주는 한 건의 유기적 Instagram 시험.
- 가설: 작품 전체 소개보다 ‘다이어리 첫 줄에 날짜를 남기는 일’이라는 구체적인 쓰임새가 저장·공유·구체적인 선호 댓글로 이어지는지 관찰한다. 수요나 알고리즘 노출은 보장하지 않는다.
- 형식: 1080×1350, 동일한 크기·위치의 3장 캐러셀. ① 카메라 모양/반전 ② 다이어리 사용 장면 ③ 잉크 색 선호.
- 선택 이유: 기존 자료는 정지 렌더뿐이고 실제 셔터 전후 동작 자료가 없다. 승인된 대안인 캐러셀을 사용한다. 실제 작동 영상처럼 보이는 합성이나 억지 움직임을 만들지 않는다.
- 이미지: 원본 `01-hero.webp`, `02-press-to-stamp.webp`, `07-ink-colors.webp`를 변경 없이 배치한다. 패키지는 첫 장에 쓰지 않는다.
- 카피: 한국어 우선 + 영어. 이미지 3장과 캡션 모두 AI 콘셉트·미제작 상태를 명시한다. 가격·구매·출시·성능 검증 표현 없음.
- 공개 전: 각 장/4:5 원본/중앙 정사각 썸네일 확인, ALT 입력, 앱의 AI 레이블 설정, 중복 게시 확인. 사이트 PM-015 활성화와 실제 SNS 링크 저장은 정상 관리자 세션으로 함께 처리한다.
- 제한: 비용 0원. 광고·구독·다른 게시물 댓글·DM·멘션·기존 글 삭제·X 복제·추가 자동 변주 없음. PM-001 보류 유지.
- 판단: 실제 공개 시각 이후 24시간·72시간·7일에 게시물별 저장·공유·구체 댓글·도달·프로필 행동을 구분해 기록. 낮은 도달과 낮은 반응을 구분하고, 운영자 QA 재생·조회는 외부 수요로 세지 않는다. 미표시 값은 null.
- 비교 한계: PM-013과 작품·형식·카피·공개 시각이 달라 통제된 A/B 시험이 아니다. 작은 수치 차이만으로 승자를 정하거나 재게시하지 않는다.
