# PixelMurmur reference accounts

확인일: 2026-09-04

## PixelMurmur 조합

핵심 조합은 다음 네 가지다.

1. 즉시 이해: 미니덕트와 NiK Bentel처럼 첫 1초에 `A가 B가 된다`를 보여준다.
2. 메커니즘 만족: Craighill과 Special Projects처럼 손과 한 동작을 화면 중심에 둔다.
3. 저장용 설명: BKID와 Design Burger처럼 히어로, 동작, 구조, 질문 순서로 구성한다.
4. 브랜드 분위기: OIMU와 Six N. Five처럼 사물의 기억과 재료감을 보조적으로 사용한다.

운영 비중은 즉시 이해 40%, 메커니즘 30%, 저장용 설명 20%, 분위기 10%를 출발점으로 삼는다. 초기에는 하루 한 작품 이하로 유지하며 한 게시물에는 하나의 기능과 하나의 질문만 둔다.

## 탐색용 여섯 형식

| 형식 | 권장 플랫폼 | 첫 화면 | 주 지표 |
| --- | --- | --- | --- |
| 기능 즉시 루프 | Instagram 7–9초, X 5–6초 | 완성 동작부터 시작 | 완주, 반복 재생, 공유, 프로필 행동 |
| 한 문장 히어로 | X 1장 1:1 또는 4:5 | 제품이 화면의 70% 이상 | 이미지 확장, 북마크, 재게시, 프로필 행동 |
| 작동 원리 캐러셀 | Instagram 4–5장 4:5 | 완성 형태→동작→구조→질문 | 저장, 공유, 의미 있는 질문 |
| 과정 캐러셀 | Instagram 5장, X 최대 4장 | 과정과 완성 형태를 대비 | 저장, 구체적 피드백, 팔로우 |
| 색상·재질 투표 | Instagram 또는 X 2×2 | 네 변형을 동시에 노출 | 선택 응답, 제작 의향 |
| 실제 사용 장면 | Instagram 9–12초, X 1–3장 | 손과 사용 환경부터 시작 | 공유, 프로필 행동, 사용 장소 응답 |

최초 여섯 형식은 각 한 번씩 시험한 뒤 승패를 판단하지 않는다. 한 형식을 서로 다른 오브젝트 세 개에서 반복하고 각 게시물을 최소 72시간 관찰한 뒤 잠정 판단한다. 최종 비교는 7일 수치를 사용하며 Instagram과 X의 조회수는 서로 직접 비교하지 않는다.
