# PixelMurmur Motion Studio

PixelMurmur의 정지 콘셉트 렌더를 Instagram과 X용 세로 영상으로 변환하는 재사용 가능한 Remotion 프로젝트다.

## PM-001

```bash
npm install
npm run dev
npm run lint
npm run render:pm001:reel
npm run render:pm001:loop
npm run still:pm001
```

결과물은 `../campaigns/2026-09-pilot/PM-001/video/renders/`에 저장된다.

- `pm-001_ig_12s_v01.mp4`: 12초 Instagram Reel
- `pm-001_ig_loop_06s_v01.mp4`: 6초 Instagram/X 루프
- `pm-001_reel_cover_v01.png`: Reel 표지

두 영상은 1080×1920, 30fps, H.264, 무음으로 렌더한다. 게시 승인 뒤 플랫폼에서 사용 가능한 라이선스 음원을 선택한다.

모든 장면에는 아래 고지를 유지한다.

```text
CONCEPT RENDER · NOT PRODUCED
콘셉트 렌더 · 아직 제작되지 않음

MOTION VISUALIZATION
동작 시각화
```

이 프로젝트는 영상을 만들 뿐 SNS에 게시하거나 광고를 집행하지 않는다.
